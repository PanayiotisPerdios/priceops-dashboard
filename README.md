# PriceOps Dashboard

Prerequisites

- Node.js
- npm

# Installation

1.Clone the repository:
```dotenv
git clone https://github.com/PanayiotisPerdios/priceops-dashboard
cd priceops-dashboard
```
2.Install the project dependencies:
```dotenv
npm ci
```
This installs the dependencies specified in package-lock.json.

# Running the Development Server

Start the local development server:

```dotenv
npm run dev
```
